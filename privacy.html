Privacy policy

Last updated: 19 November 2026

Campfire Studio is a private application used only by the owner of the YouTube channel Campfire Stories. It has no other users.

What data it accesses

With the owner's permission, it uses read-only access to the YouTube Data API and the YouTube Analytics API to read the owner's own channel information: the list of uploaded videos (titles, durations, publish times) and their statistics (views, average view percentage, audience retention, subscribers gained).

How the data is used

The data is used only to show the owner how the channel's videos perform and to help plan future videos. It is never sold, shared with third parties, or used for advertising.

Where it is stored

The data and the access token are stored on the owner's own computer and private server. The application cannot upload, edit or delete anything on YouTube.

Google API Services

Campfire Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: contact the owner through the Campfire Stories YouTube channel.
